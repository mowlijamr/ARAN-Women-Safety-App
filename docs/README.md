# ARAN Documentation

Welcome to the documentation folder for **ARAN – Women Safety & Emergency Assistance**.

This folder is designated for storing important project media and supplementary materials.

## Required Materials

To complete the repository representation, please upload the following files into this folder:

- `app_demo.mp4` : A short demonstration video showing the SOS flow and Shake Detection.
- `screenshot_home.png` : Main home screen showcasing features.
- `screenshot_emergency.png` : The active emergency session screen.
- `screenshot_offline_guide.png` : The Quick Safety Guide screen in Tamil and English.
- `hackathon_certificate.pdf` or `.png` : Verification of the 1st Prize achievement.
- `team_photo.jpg` : (Optional) Photo of the hackathon team.
- `architecture_diagram.png` : A block diagram of the Flutter app's integration with device sensors and services.
